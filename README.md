# BigBoy Productions | Portfolio v2.0

Cinematic portfolio voor Liam van Woudenberg - Freelance Director of Photography & Photographer.

## 🚀 Kenmerken
- **Cinematic UI/UX**: Geïnspireerd door high-end filmproducties.
- **Dynamic Portfolio**: Haalt foto's rechtstreeks op uit GitHub mappen.
- **SEO Geoptimaliseerd**: Inclusief JSON-LD structured data, sitemap.xml en robots.txt.
- **Client-side Validatie**: Robuust contactformulier met real-time feedback.
- **CMS Dashboard**: Beheer content zonder de code aan te raken via `/admin`.

## 🛠 Tech Stack
- **Framework**: React 19 (ESM)
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Deployment**: GitHub Actions + GitHub Pages

## 📦 Installatie & Gebruik
1. Clone de repository.
2. Installeer dependencies: `npm install`
3. Start development server: `npm run dev`
4. Bouw voor productie: `npm run build`

## 🌍 SEO Informatie
De site is geoptimaliseerd voor lokale zoektermen in **Utrecht, Amsterdam, Rotterdam en Den Haag**.
De sitemap bevindt zich op `public/sitemap.xml`.
